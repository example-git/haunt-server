# Security policy

Haunt Server has not received an independent security audit. Its authentication,
encrypted-message transport, media relay, storage, update, and deployment
boundaries are described in the repository documentation and should not be
treated as guarantees beyond the tested behavior.

## Supported versions

Security fixes target the current `main` branch and the newest published server
release. Operators on older releases should expect to upgrade.

## Reporting a vulnerability

Use this repository's GitHub **Report a vulnerability** feature. If it is
unavailable, contact a repository owner privately. Do not open a public issue
for a suspected vulnerability.

Include the affected commit, deployment assumptions, impact, reproduction steps,
and mitigation if known. Remove credentials, private messages, access tokens, and
personal data from the report. The project does not currently promise a response
SLA or bug bounty.
